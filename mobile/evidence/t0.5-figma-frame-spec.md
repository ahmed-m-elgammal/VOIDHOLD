# T0.5 Figma Evidence Frame Specification

Status: **Figma board not attached**

Required coverage is 12 screens × 2 orientations × 2 locales = **48 frames**. Use 1280×720 for landscape and 720×1280 for portrait. Arabic frames must be true RTL variants, not English screenshots with translated text pasted in.

| ID | Screen | Required states |

| 11 | Save/load/recovery | normal save, interrupted write, recovery |
| 12 | Combat/authority | flyer incident, authority range, repair response |

## Required component rules

- Touch targets are at least 48dp.
- Landscape uses full HUD, three-tab BuildBar, and right inspector.
- Portrait uses compact HUD, collapsible BuildBar drawer, and full-screen sheets.
- Safe-area, cutout, gesture-navigation, foldable, and split-screen variants are shown.
- Arabic mirrors layout direction, icon/meter direction, focus order, and navigation hierarchy.
- Warnings use icon + label + color; color is never the only signal.
- Include a 200% text-size frame for the inspector and warning center.
- Include placement ghost, reason toast, warning haptic, and back-button hierarchy.
