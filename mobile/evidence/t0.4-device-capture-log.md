## Capture protocol

1. Cold-launch the spike build and record startup time.
2. Record landscape and portrait video while placing, selecting, panning, zooming, rotating, opening sheets, and triggering one warning.
3. Run the worst-case slice fixture: full dome, active resource logistics, both castes, carrierbot, and one flyer incident.
4. Record frame-time p95, p99, FPS, draw calls, triangles, process RAM/PSS, GPU memory where available, and renderer.
5. Run a 20-minute thermal soak. Record ambient temperature, start/end skin temperature, throttling, and sustained frame rate.
6. Run the four-hour offline fast-forward fixture and record wall-clock duration, ANR/crash result, and replay hash.
7. Run call, lock, airplane mode, low-storage, and kill-during-write interruption cases.
