## 4. Best practices (builder genre)
- 5-min-to-fun: first dome productive without wiki. Tutorial must teach failure states, not just placement.
- One new system per 3 minutes in FTUE. No stacked tutorials.
- Numbers visible: never hide why productivity dropped (oxygen/damage/mood breakdown required in inspector).
- Fair lose: warn 60s before starvation/destruction. No instant fail on mobile.
