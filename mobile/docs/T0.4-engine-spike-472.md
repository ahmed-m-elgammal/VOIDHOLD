## 1. Spike scope (throwaway allowed, but decisions must be promoted)

- [ ] 16KB check: run alignment check on AAB + native libs. Rebuild any stale `.aar` with NDK r28+.
- [ ] Edge-to-edge + gesture nav + cutout test landscape + portrait. Back-button hierarchy test.
- [ ] Interrupt test: call, lock, airplane, low storage. Must autosave, no crash.
- [ ] Sim timing spike: fixed 20 Hz simulation, render interpolation, pause/resume, 3x speed, and bounded 4-hour fast-forward.
- [ ] Test a portrait/landscape window resize, split-screen, and safe-area change without losing camera or UI state.

## 4. Best practices (Godot mobile)
- Never ship Forward+ to phones. Preview realistic PBR on PC, validate on Mobile renderer weekly.
- One directional light + baked AO. No per-building realtime lights.
- Ortho for gameplay (placement accuracy), perspective only for menus.
- Keep spike separate from production project if messy — promote only config + camera learnings.
