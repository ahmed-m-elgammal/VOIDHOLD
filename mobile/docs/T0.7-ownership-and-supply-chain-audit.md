# T0.7 — Ownership + Software Supply-Chain Audit

Owner: Producer + legal reviewer. Reviewer: Tech Lead.

## Goal

Prove that the remake can be commercially distributed, and document every external dependency before production assets or code are promoted.

## Tasks

- [ ] Confirm rights to reuse, port, modify, and commercially distribute the original game code and data.
- [ ] Inventory every file under `images/`, `imagesoga/`, `ogaunused/`, `music/`, `sounds/`, `maps/`, `lib/`, fonts, plugins, and future Godot addons.
- [ ] Record author, source URL, license, attribution, redistribution terms, share-alike obligations, and commercial permission.
- [ ] Audit GameJS, jQuery, Mustache, Raphael, PRNG code, fonts, SDKs, codecs, and native libraries.
- [ ] Define `THIRD_PARTY_NOTICES.md`, `CREDITS.md`, and `art_manifest.csv` formats.
- [ ] Define a build scan that fails when unapproved paths or missing provenance enter a release export.

## Accept

- [ ] Original-code permission or ownership evidence is attached.
- [ ] Every shipped dependency has a license decision.
- [ ] Ambiguous assets are quarantined, not silently retained.
- [ ] Notice and attribution outputs are generated from the approved manifest.
- [ ] Audit is reviewed before T0 exit.
