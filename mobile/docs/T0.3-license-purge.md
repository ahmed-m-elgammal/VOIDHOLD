# T0.3 — License Purge + Asset Replacement Plan (Docs only)

Owner: Producer + artist. Reviewer: Engineer.
Inputs: `images/`, `imagesoga/`, `music/*.ogg`, `sounds/`, `maps/map.tmx` tileset sources.
Output: ship-safe asset list + replacement budget.

## 1. Audit tasks
- [ ] Inventory every file under `images/` + `imagesoga/` + `ogaunused/` + `music/` + `sounds/` + `maps/` + `lib/` + fonts and future addons. Record: source (LPC/OpenGameArt/etc), license (CC0/CC-BY/CC-BY-SA/GPL?), author + URL, commercial allowed? attribution required? share-alike triggers?
- [ ] Confirm ownership or commercial permission for the original source code and data, not only the art and audio.
- [ ] Audit embedded libraries and build tools (`GameJS`, jQuery, Mustache, Raphael, PRNG code, fonts, codecs, SDKs, native libraries).
- [ ] Mark: KEEP (CC0 only) / REPLACE / NEED-LAWYER. Default to REPLACE for anything ambiguous.
- [ ] Mark all generated, purchased, kitbashed, or commissioned replacements with provenance and human reviewer.
- [ ] Special attention: `lpc-skorpios-scifi-sprite-pack`, `lpc-tile-atlas2`, `tiled-terrains/terrain.png`, `1-hour-lpc-enemy`, `lpc-beetle`, all 11 music tracks. Assume REPLACE unless proof of CC0.
- [ ] Record tileset dependency: `map.tmx` references OGA tiles — visual tiles will be replaced by procedural PBR ground shader, logical properties kept. No OGA pixels ship.
- [ ] Define a release scan that fails if unapproved paths, missing provenance, or quarantined assets enter `art_final/` or an export.

## 2. Replacement plan
- [ ] Buildings (18 source types unless a separate 19th is approved) -> authored low-poly PBR sets. Props trim sheets. Units (5 rigs). Ground/snow/rock/ice. VFX. UI icons. Music 6 adaptive tracks + full SFX set (-14 LUFS).
- [ ] Estimate per asset: model + texture + LOD + collision. Flag hero vs background quality.
- [ ] Attribution file plan: `CREDITS.md` + in-game About, even if zero OGA remains.
- [ ] Third-party notices and source-code license evidence are linked from the release checklist.

## 3. DB / code impact
- No asset paths hard-coded in sim. Plan `art_manifest.csv`: old path -> new GUID -> license. Sim references GUIDs only. Prevents re-contamination.

## 4. Best practices
- Never commit new OGA downloads to `art_final/`. Quarantine in `art_inbox/` with license txt.
- Commercial + CC-BY-SA = do not ship. Re-create, don't re-license.
- Keep audit sheet in repo; stores + publishers will ask.
- No unreviewed generated, placeholder, or provenance-free asset enters `art_final/`.

## 5. Accept
- [ ] Audit sheet complete with license + decision per file
- [ ] Replacement list costed + prioritized (blockers for Epic 5 flagged)
- [ ] `art_final/` policy + manifest format approved
- [ ] Original-code and dependency ownership evidence attached
- [ ] Zero code, zero new binary assets in this task
