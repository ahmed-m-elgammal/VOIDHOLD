# T0.6 — Data / DB / Save Schema Design (Paper only, no implementation)

Owner: Client engineer + designer. Reviewer: QA.
Inputs: T0.2 entity list, T0.5 strings_en/ar + warnings. Game: `VOIDHOLD` (`com.voidhold.colony`). Target: Godot `user://slot%d.json`, future cloud + RevenueCat entitlements.
Output: versioned schema + dictionaries approved before Epic 1.

## 1. Design
- [ ] Top-level: `save_version=1, game_version, content_version, playtime_s, last_seen_utc, rng_state, camera(topleft, zoom, rotation), planet(seed, moon_id, map_version), domes[], entitlements{}, settings{}, stats{}, tutorial_flags`.
- [ ] Dome: `guid, topleft, width, buildings[guid], units[guid]`.
- [ ] Building: `guid, type (immutable id), display_id (localizable), topleft, rotation, dome_guid, damage, repair_cooldown_ms, hasEnergy, userMaxWorkers, update_remaining_ms, outputStorage, storage{stone,alloy,biomass,ore,stim}, attached_buildings[], workers[], incoming_workers[], residents[], mission_workers[], incoming_mission_workers[], incident_guid, incoming_incident_guid, extra{import,export}`.
- [ ] Unit: `guid, caste (crew/officer), name_id, happiness, fullness, dome_guid, position, direction, send_home, elevator_down, idle_count, day_state{type,building_guid,route[],route_cursor,resolve_ms,had_job}, job_state{type,building_guid,origin_guid,output_guid,route[],route_cursor,resolve_ms}`, carrying `{resource,amount}`.
- [ ] Enemy: `guid, type, hp, damage_per_second, position, direction, day_state{type,target_guid,route[],route_cursor,time_remaining_ms}, job_state{type,building_guid,resolve_ms} (null unless mid-attack; same shape as unit job_state minus origin/output)`.
- [ ] `settings{locale(en|ar), music(bool), sfx(bool), haptics(bool), quality(low|med|high), reduced_motion(bool)}`, `stats{produced{5}, consumed{5}, colonists_born, colonists_lost, buildings_built, buildings_lost, sieges_repelled}`, `entitlements{}` (reserved empty dict for Epic 8 RevenueCat; no store logic in v1), `tutorial_flags{ftue_step(int 0-7), completed(bool)}` — zero open fields.
- [ ] Rules: internal IDs immutable forever. Display names via `strings.csv`. Numeric ranges + clamps documented. GUID format `hex32`. All refs by GUID, never by index.
- [ ] Migration plan: `v0->v1` loader stub, corrupt-save backup + recovery flow, max 3 slots + autoslot + thumbnail spec.
- [ ] Define whether interrupted jobs resume exactly or safely recompute from persisted targets; dangling references must self-heal without deleting the whole save.

## 2. Data dictionaries (paper)
- [ ] `buildings.json` fields from TYPES, `tech_tree.json` from PRECONDITIONS/TABS, `moons.json` (3 difficulties + multipliers), `balance.json` (timers/costs + mobile proposal), `tuning.tres` thresholds.
- [ ] Canonical resource IDs are `stone`, `alloy`, `biomass`, `ore`, and `stim`; legacy source keys are retained only in an import mapping.
- [ ] Validation rules: cost>=0, workers<=max, damage 0-1, storage caps, import/export allowlists.

## 3. UI/UX + QA hooks
- Every persisted field must be viewable or debuggable (inspector or debug overlay). No invisible state.
- QA needs: save-corruption test saves, full-dome stress save (80x80), orientation-switch mid-save test.

## 4. Best practices (game saves)
- Version every save. Never delete player save on load failure — quarantine + copy.
- Atomic writes (tmp + rename). Autosave 30s + on focus-out. Offline progress computed from `last_seen_utc`, capped 4h, no grant logic in Epic 0.
- `entitlements:{}` reserved for RevenueCat later. No store logic now.
- Scoped storage (API 36) + iOS sandbox paths documented, no absolute paths in saves.
