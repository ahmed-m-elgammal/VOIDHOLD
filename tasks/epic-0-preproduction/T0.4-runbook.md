# T0.4 Runbook — Godot 4.7.2 Spike (throwaway allowed)

Binary: set `GODOT_BIN` env to local Godot 4.7.2 console exe (do not hardcode Downloads paths). Verified build `4.7.2.stable.official.ed1daf0bf`.
Target: Android `targetSdk 36` + iOS stub. Renderer: test Mobile (Vulkan on Android / Metal on iOS) and Compatibility (OpenGL ES) separately per T0.4 spec — never label GLES3 as Mobile. Forward+ PC preview only.

## Steps
1. New empty 4.7.2 project in `spike/` (outside production `project/`). Ortho Camera3D, 1 dome ring, 1 greybox habitat, 1 drone waypoint loop, drag/pinch/rotate.
2. Export AAB with `targetSdk 36, minSdk 24, Gradle 8.7+, JDK 17+, Platform 36, NDK r28+`. Run 16KB alignment check on AAB + .so.
3. Run on API 36 emulator AND required physical low-end Android + physical iPhone (emulator alone never counts for perf). Log fps/p95/tris/calls/RAM/thermal + video landscape + portrait.
4. iOS: export stub, install simulator/TestFlight, log same + safe-area + ATT conditional note.
5. Interrupt matrix: call/lock/airplane/storage-full/kill-during-write. Must autosave stub, no crash.
6. Record renderer + tiers (Low/Med/High) + import presets for Epic 1.
